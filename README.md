# Tech Portal Pakistan - Theme Repository

Custom theme for Tech Portal Pakistan news portal.

## Structure

- `colormag/` - Parent theme (ColorMag v4.2.2)
- `techportal-child/` - Child theme with customizations

## Brand Colors

- Primary: #37215F (Pakistan purple)
- Secondary: #0881BE (tech blue)
- Accent: #F14E32 (orange-red)
- Success: #1E8449 (green)
- Dark BG: #1A1A2E (dark blue-gray)

## Installation

1. Upload both `colormag/` and `techportal-child/` to `wp-content/themes/`
2. Activate `Tech Portal Child` theme in WordPress admin
3. Configure colors and settings via Appearance > Customize

## Development

Child theme modifications go in `techportal-child/`. Never edit parent theme files directly.
